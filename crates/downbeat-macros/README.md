# downbeat-macros

The `#[job]`, `#[command]` and `#[derive(JobData)]` macros of [downbeat](https://github.com/downbeat-rs/downbeat).

Use them through the `downbeat` crate, which re-exports them; this crate is not meant to be depended on directly.
