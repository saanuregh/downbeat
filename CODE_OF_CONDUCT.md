# Code of conduct

downbeat follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep criticism about the work, not the person.
Harassment of any kind is not tolerated, in issues, pull requests, reviews or anywhere else the
project meets.

To report a problem privately, use GitHub's
[private vulnerability reporting](https://github.com/downbeat-rs/downbeat/security/advisories/new)
form and say that it is a conduct report, or contact a maintainer directly. Reports are kept
confidential, and the maintainers will act on them as the Covenant's enforcement guidelines
describe.
